## 🚀 Projetos

### ⚔️ [Aventura Python 3D - 3 Dungeons](./jogo-aventura-python)
Jogo de ação e aventura em 3D desenvolvido em Python utilizando a engine **Ursina** e renderizador **Panda3D**.
- **Destaques:** Câmera 3D dinâmica com colisão, 3 dungeons com cenários/texturas personalizadas, sistema de combate (ataque básico, ataque giratório e escudo de defesa), IA de inimigos e chefes com projéteis (bolas de fogo).

### 📚 [Gerenciador de Biblioteca Desktop](./biblioteca)
Aplicação desktop completa com **Interface Gráfica (Tkinter)** e banco de dados relacional **SQLite**.
- **Destaques:** Migrado de aplicação DOS para GUI nativa, CRUD de livros e categorias (relacionamento N:N), filtros de busca combinados, ordenação dinâmica de colunas e painel de estatísticas do acervo. Compatível com Windows 7 (32-bits).

### 📖 [Diário Pessoal](./diario-pessoal)
Aplicação em Python para registro e gerenciamento de anotações pessoais com armazenamento em JSON.

### 🕒 [Sincronizador de Hora para Windows](./sincronizador-de-hora)
Utilitário para correção automática de data/hora do Windows via API externa, resolvendo problemas de bateria CMOS descarregada e certificados SSL no Windows 7.

### 🃏 [Blackjack](./blackjack)
Implementação do clássico jogo de cartas 21 para prática de lógica de programação e estruturas de controle.

### ❌ [Jogo da Velha](./jogo-da-velha)
Jogo da velha em terminal com verificação automática de vitória e empate.

### 💳 [Validador de Cartão](./validador-cartao)
Validador matemático de números de cartão de crédito baseado no Algoritmo de Luhn.
