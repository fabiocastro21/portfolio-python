## 🚀 Projetos

### 📚 [Gerenciador de Biblioteca Desktop](./biblioteca)
Aplicação desktop completa com **Interface Gráfica (Tkinter)** e banco de dados relacional **SQLite**. Permite cadastrar, editar, filtrar e ordenar livros e categorias, além de exibir estatísticas visuais do acervo.
- **Destaques:** Migrado de uma aplicação em terminal DOS para GUI nativa, suporte a relacionamentos N:N (livro-categoria), filtros combinados de busca e compatibilidade completa com Windows 7 (32-bits).

### 📖 [Diário Pessoal](./diario-pessoal)
Aplicação em Python para registro e gerenciamento de anotações pessoais com armazenamento em JSON.

### 🕒 [Sincronizador de Hora para Windows](./sincronizador-de-hora)
Utilitário desenvolvido para corrigir automaticamente a data e hora do Windows através de consulta a uma API externa.
- **Principais desafios resolvidos:**
  - Compatibilidade com Windows 7
  - Problemas de certificados SSL
  - Tratamento de erros
  - Geração de executável com PyInstaller
  - Solução para computadores com bateria CMOS descarregada

### 🃏 [Blackjack](./blackjack)
Implementação do jogo Blackjack para prática de lógica de programação e estruturas de controle.

### ❌ [Jogo da Velha](./jogo-da-velha)
Versão em terminal do clássico jogo da velha, com verificação automática de vitória e empate.

### 💳 [Validador de Cartão](./validador-cartao)
Aplicação para validação de números de cartão utilizando algoritmo matemático (Algoritmo de Luhn).
