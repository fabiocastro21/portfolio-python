# Sincronizador de Hora

Aplicação desenvolvida em Python para corrigir automaticamente a data e hora do Windows.

## Problema

O projeto foi criado para resolver falhas causadas por uma bateria CMOS descarregada, que fazia o computador iniciar com data incorreta.

## Solução

- Ajusta inicialmente a data para um valor válido.
- Consulta uma API de horário.
- Atualiza automaticamente a data e hora corretas.
- Compatível com Windows 7.

## Tecnologias

- Python
- Requests
- PowerShell
- PyInstaller

## Aprendizados

- Consumo de APIs
- Tratamento de erros
- Certificados SSL
- Compatibilidade com sistemas legados
