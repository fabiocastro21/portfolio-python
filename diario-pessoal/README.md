# Diário Pessoal

Aplicação em Python para registro de anotações pessoais.

## Funcionalidades

- Criar entradas
- Listar registros
- Excluir registros
- Armazenamento em JSON
- Registro automático de data e hora

## Tecnologias

- Python
- JSON
- Datetime

## Objetivo

Projeto criado para praticar manipulação de arquivos e persistência de dados.
